# 0.5：具体供应商的离线预检

## 为什么先选 Gemini Developer API

选择它作为**预检样本**，不是对用户账号可用性或零费用的推荐。官方文档明确区分免费与付费层级、项目与密钥、模型资格和可用地区，适合把缺失条件做成明确阻塞项。它并非对所有地区、所有模型、所有使用场景免费。

2026-11-17 查阅的官方来源：
- [计费与层级](https://aistudio.google.com/docs/billing)：免费层仅支持部分模型与额度，关联计费账户会改变资格。网页聊天免费不能推导 API 免费。
- [可用地区](https://aistudio.google.com/docs/available-regions)：需按实际访问地区及面向用户的地区核对；不能把代理连接成功视为地区资格验证。
- [服务条款](https://aistudio.google.com/docs/terms)：涉及年龄、开发者/商业用途、地区、部分地区仅允许付费服务以及数据处理等限制。需要完整审阅对应场景，不是勾选一个布尔值就合规。
- [当前模型定价](https://ai.google.dev/gemini-api/docs/pricing)：真实接入前重新核对确切模型与能力；此版本不保存会过时的“永久免费模型名单”。

不自动创建账号、不领取优惠、不通过轮换账号绕过额度、安全拒绝或地区限制。

## 使用

```sh
python preflight.py examples/gemini-preflight.json
```

这是**离线配置声明检查**，不登录、不读取账号状态、不读环境变量、不联网、不读系统密钥库。JSON 示例不含密钥，模型是占位符。只接收指定字段，拒绝额外字段，未知字段名和值不回显。请勿把 API key、token、密码、项目私密标识填入配置。

输出：
- `declaration_checks_complete`：仅说明所填字段满足本地格式/声明条件。
- `account_verified=false`、`eligible=false`、`can_call=false`：无论填什么，都不能产生真实授权。
- `blockers`：固定安全原因码，不回显输入内容。
- 退出码始终为 `2`，表示真实调用被阻止；不是安装故障。

`checked_at` 为声明检查时间的 Unix 秒；超过 24 小时、未来时间、NaN 或非法类型视为过期/无效。该时间及其他输入都可由用户编辑，因此不能当作可信证据。

`credential_store=os-keyring` 只是未来目标的声明；本版没有实现密钥库。填写 `billing_tier=free` 或 `hard_stop_verified=true` 也不会证明平台真的不收费。

## 正式调用的阻塞清单

1. 用户与应用场景在供应商服务条款和支持地区范围内；如果不满足则换合法可用的平台，而非绕过限制。
2. 具体项目/密钥/模型/请求能力绑定核验，确认账户未启用会产生费用的付费路径。
3. 验证平台免费额度耗尽后的行为及收费硬边界。无可验证的硬停止机制就不能承诺零账单。
4. 使用经用户授权的操作系统密钥库；不把密钥放入前端、仓库、日志或聊天。部署环境和密钥库需要实际系统测试。
5. 用户明确批准具体平台及发送的数据范围；审查免费服务的数据处理条款，不发送敏感研究或客户资料作为试探。
6. 完成平台专用协议、错误语义、限流、超时结果不确定的处理，再进行用户批准的有限真实联调。

本阶段只交付第一层离线预检，**未实现账号只读 API 验证**。它不能知道账户余额、密钥有效性或地区资格。真实调用仍被 `providers.evaluate` 的硬阻断保护。没有真实供应商开关，没有 CI。
