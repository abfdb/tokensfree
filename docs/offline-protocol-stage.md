# 0.4 阶段验收：离线协议与客户端闭环

## 当前可以用

运行 `python server.py`，另开终端运行 `python client.py`。客户端会获取本地会话令牌，通过最小 chat completion 格式提交文本，并显示固定模拟响应。它只访问 `127.0.0.1`，不使用系统代理、不跟随重定向、不自动重试。

程序化调用：

```python
from client import LocalClient
client = LocalClient(port=8765)
result = client.complete('test', request_key='my-task-001')
```

建议调用方预生成 request_key 并保存。省略时客户端生成的键可从 `client.last_request_key` 取回（在网络请求前写入；客户端实例不要并发共享）。不确定重试时复用同一个 request_key；新任务必须换键。去重只在同一服务进程 5 分钟窗口内有效，不是跨进程 exactly-once。

## 权限与凭证边界

服务端 `Gateway(authorized_providers=...)` 是可信授权上限。请求里的 allowed_providers 只能缩小范围，不能新增权限。空服务端集合意味着所有请求停止。网页没有权限提升或供应商密钥入口。

本地会话 token 仅代表当前进程访问能力，不是供应商凭证。真实凭证的读取、保存、系统密钥库、OAuth 和账号授权仍未实现。本机恶意进程不在本原型保护边界内。

## 协议适配范围

新增离线 HTTP 协议模块，用本地 fixture 对请求编码、响应解码、错误归一化和失败关闭做验证。它不连接真实供应商，没有平台余额/免费资格校验，也没有在主网关中启用真实调用开关。主控制台继续运行 deterministic mock。

本阶段不是完整 OpenAI SDK 兼容声明，不支持流式、图片、工具调用和任意第三方客户端。测试替身不能证明某供应商实际格式、免费政策、认证或计费行为正确。

## 进入真实联调前

1. 选定具体供应商和账户；核对条款及明确的免费硬停止能力。无法证明不会自动付费则仍阻止。
2. 凭证放入用户批准的本地密钥库，固定绑定供应商、模型和 HTTPS 主机，不把密钥提交仓库、发送浏览器或记录日志。
3. 服务端维护账户级授权、免费资格有效期及调用预算；客户端不能自行声明免费。
4. 用户批准具体数据发送目的地与测试额度后才能真实联调。真实请求超时的结果不确定，不能未经判断切换重放，以免重复消耗/输出。
5. 测试平台实际 429/鉴权/额度/安全拒绝语义，完成跨系统安装与第三方客户端验证。

未配置 CI；每个阶段本地运行测试并独立审查。不发布公网服务，不改变仓库私有性。

协议字段参考：[官方 Chat Completions 参考](https://developers.openai.com/api/reference/resources/chat)。仅借鉴文本非流式子集；`max_tokens` 并非所有型号都支持，未来需供应商专属映射。

本阶段测试覆盖本地 HTTP 往返、重定向阻断、字节上限、错误正文脱敏、安全拒绝、权限收缩和客户端重复键保护。协议 fixture 有调用截止定时器；最小客户端后续也增加了每次 HTTP 交易的截止定时器，详见 [客户端安全说明](local-client-safety.md)。请只连接自己启动的本地服务，不发送敏感数据到 fixture。
