# 本地客户端传输可靠性

`client.py` 继续只连接固定 `127.0.0.1`，不接受远端 URL，不读取代理环境，不自动重试或跟随重定向。

本次修复了原来 socket 空闲超时可被慢速响应不断延长的问题。现在每一次 HTTP 交易都有截止定时器，包括响应头和正文阶段；超时关闭 socket。`complete()` 包含获取会话令牌和提交文本两次交易，因此不是整个调用共享一个 timeout。系统调度可能造成少量误差，不承诺实时系统级精度。

成功响应必须是 JSON，拒绝内容编码、重复 Content-Length、Content-Length 与 Transfer-Encoding 混用、超大正文、重复 JSON 字段和 NaN/Infinity。错误响应不读取或显示上游正文；传输及 JSON 错误使用固定说明，避免错误字符串包含敏感响应内容。

会话令牌须符合本地服务生成的 URL-safe 格式；错误类型、换行或异常值不会进入 POST 请求头。该校验不是对本地服务身份的认证，无法防御恶意本机进程占用服务端口；仍应只连接自己启动的 tokensfree 服务。

遇到不确定超时不自动重发。调用方应提前保存 request_key；省略时可查看 `client.last_request_key`。同进程缓存只有既有的五分钟窗口，服务重启或缓存过期后不能承诺去重。

本阶段仅完善已经存在的本地客户端，不新增供应商或真实外网出口，不改变 UI、CI 或收费行为。回归测试通过本地测试服务制造慢速响应与异常帧，无账号或 API key。

本轮新增 13 项实际 loopback HTTP 回归测试，包含慢响应头、慢正文、重定向、非法类型/编码、重复/截断长度、超限、错误正文脱敏和会话令牌注入。独立审查发现“声明长度大于实际正文但 JSON 完整时被接受”，已增加严格字节数匹配，防止接受截断响应。
