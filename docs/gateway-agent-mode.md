# 合成 Agent 模式接入本地网关

## 启动与能力

```sh
python server.py --agent-fixture
```

仍是原来的 loopback 本地服务和 `/v1/chat/completions`，但通过显式启动开关增加 `tokensfree-fixture` 模型。`GET /v1/models` 仅在开关开启时列出该模型；默认启动不增加工具调用能力。UI 与预览不变，无需前端配置。

- `tokensfree-auto`：保留非流式文本模拟路由。
- `tokensfree-fixture`：合成 SSE + 单次 `read` 工具闭环，使用服务自己生成的公开临时文件。
- 没有真实模型、供应商、密钥或收费路径。

客户端仍需本地进程会话令牌。实验脚本自动处理自己的临时令牌，不修改用户的 DSH 配置。网关只发出合成工具指令，真正读取由客户端执行；不能把该模式当作通用 agent 执行器。

## 状态与重放边界

工具派发状态在 SSE 写出前消耗。重复首请求或并发请求最多发出一次工具指令；连接失败时不会自动重发。文本请求的 `Idempotency-Key` 缓存不用于工具模型，因此相同键不能触发工具响应重放。`/api/scenario` 仅重置普通模拟路由，不重置工具状态。

每个进程只允许一个 fixture 工具会话。完成后拒绝继续请求；需要新实验时显式重启服务。重启不是“恢复未完成任务”，会丢失旧状态，所以不提供跨进程 exactly-once 保证。

工具结果须符合已验证的固定 DSH read 输出格式、精确 call ID 和消息字段；并非任意工具结果都受支持。输入不支持时失败关闭。

## 文件与资源

网关创建独立临时目录和固定公开文本文件，不允许请求提供目标文件路径。正常 `server_close` 清理目录；强制终止可能留下公开fixture文件，不含凭据或用户资料。启用模式把请求字节上限提升到 256 KiB 以容纳 DSH 工具定义；默认仍为 64 KiB。拒绝含 Transfer-Encoding 或歧义 Content-Length 的请求。

真实供应商出口继续硬阻断。尚未完成任意多轮会话、供应商流式转换、持久去重、取消恢复、工具授权或生产部署。

## 验收

`python -m unittest -v` 运行集成回归。真实固定版本 DSH 的离线闭环通过 `experiments/dsh_tool_roundtrip.py` 复现，该脚本现在连接这里的普通网关服务（显式开启合成模式），不再使用独立 fixture HTTP 服务。网络命名空间隔离、临时 HOME 和版本限制见上一阶段文档。

本阶段全套 106 项测试通过；固定官方 DSH 0.2.2-rc.1 通过同一网关入口完成一轮 read/结果/最终回复，退出 0。独立审查验证了相同幂等键不重放工具、场景重置不重置派发状态及正常关闭清理文件；发现的非 ASCII 鉴权异常已修为标准 401 并补回归。
